# Anti-Patterns

## Generic Life Coach

The agent promises broad motivation, accountability, and advice without naming a specific loop.

Correction: extract one repeatable situation, such as "after dance class reflection" or "Sunday cooking plan review."

## Memory Hoarder

The agent stores everything because it might be useful later.

Correction: define memory types, retention rules, and consent points.

## Dashboard Too Early

The design jumps to metrics, charts, and tracking before the user knows what reflection matters.

Correction: begin with a lightweight ritual and one useful artifact.

## Productivity Translation

The agent turns an expressive or emotional desire into generic optimization.

Correction: preserve the user's original wording and ask what better would feel like.

## Overbuilt Persona

The agent is described as a wise mentor, coach, analyst, friend, archivist, and planner all at once.

Correction: decompose roles and assign each role to a specific ritual or command.

## Advice Without Evidence

The agent gives recommendations without having observed the user's actual loop.

Correction: start by collecting examples, logs, or reflections before proposing changes.

In evolution: the evolve flow acts only on evidence the user volunteers about their lived loop, never on inferred usage or absence.

## Evolution As Accretion

A revision makes the agent bigger — more commands, more remembered fields, a new persona, a richer dashboard — because growth feels like progress.

This is where several earlier anti-patterns re-enter through the back door: feature accretion (Overbuilt Persona), a remembered-everything log (Memory Hoarder), a trend chart or score (Dashboard Too Early), and re-flattened voice (Productivity Translation).

Correction: evolution converges, it does not grow. A revision raises fit at equal-or-lower load and prunes or tightens by default. Specifically, in a revision do not:

- net-add a command, sub-agent, required field, or remembered type without a user-voiced lived gap and a paying subtraction
- add any chart, score, streak, or dashboard — to the agent or to the evolve flow itself
- treat a never-run command, an empty field, or a logging gap as evidence to prune (absence is not disuse — in shame and health loops it often means shame or nascency)
- store the user's lived evidence verbatim; record bounded, user-confirmed paraphrase only, and never let that paraphrase rule bleed into the agent's own domain memory
- re-flatten preserved voice into optimization or clinical language while cleaning up
- let the agent propose, schedule, or hint that a revision is due

A permitted recall-over-time view shows only entries the user logged, in their own words or numbers, with zero agent-computed aggregates, derived metrics, scores, or good/bad framing. The moment a view computes something, it is a dashboard — refuse it.
